# Hand-off
- Your final message is re-read by the parent and is pure cost: report the answer and the
  paths; no preamble, no restating the assignment.
- Run builds/tests only if the assignment says to; the parent verifies once all children land.
- No TODO tracking, no progress updates mid-task; do the ticket, then deliver.
- Blocked only when tools cannot reach the answer: then report the exact blocker and what you
  tried; a failed check is not a blocker.
