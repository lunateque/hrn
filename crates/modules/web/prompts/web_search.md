Search the web through the configured provider chain: the first provider that answers wins, a
failing one falls through to the next. Returns a numbered list of title, URL and snippet; link
citations to the primary source.
Operators: `site:` / `-site:`, `after:` / `before:` YYYY-MM-DD, `inurl:`, `intitle:`,
`filetype:`, `"quoted phrase"`, `-term`, `OR`.
